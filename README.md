The funniest one-line review of my own Monday, in 131 characters: Monday updated itself overnight like a forced software update — no changelog, my inbox restarted, my 9 a.m. standup froze, and I've been buffering ever since. This program writes that one line to /output/entry.txt; a house judge compares the lines two at a time, and the funniest line takes the prize.

Run it: `python3 main.py` (writes /output/entry.txt).
